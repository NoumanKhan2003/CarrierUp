# 🚀 CareerUp Job Portal 🎯

Welcome to **CareerUp Job Portal**!  
Your one-stop solution to connect job seekers with their dream careers and employers with top talent.  
Built as part of the **Academy of Skill Development** project, this portal aims to bridge the gap between skills and opportunities.

---

## 🌟 Features

- **User Registration & Login:** Secure sign-up and login for job seekers and employers.
- **Job Listings & Applications:** Users can browse available jobs and apply directly.
- **Employer Dashboard:** Employers can register, log in, and post job openings.
- **Resume Builder:** Job seekers can create and manage their resumes using ready-made templates.
- **Advanced Job Search:** Filter jobs by category, location, company, skills, and more.
- **Job Alerts:** Users can set alerts for new job postings matching their profile.
- **Event Listings:** View and register for career-related events.
- **Feedback & Grievances:** Submit feedback, report issues, and raise grievances.
- **Admin/Management Tools:** Admins can manage users, jobs, events, and view reports.
- **Legal & Support Pages:** Includes Privacy Policy, Terms & Conditions, Fraud Alerts, and Trust & Safety information.

---

## 🛠️ Dependencies & Technologies Used

**Frontend:**
- **HTML5, CSS3:** For structure and styling.
- **Bootstrap:** Responsive design and layout components (CDN v4.5.2 & v5.3.3).
- **JavaScript:** Interactive features for UI.
- **jQuery:** Lightweight DOM manipulation.
- **Font Awesome:** Icon library for UI enhancements.

**Backend:**
- **PHP:** Server-side scripting for business logic and data handling.
- **MySQL:** Relational database to store user, job, and application data.

**Other Integrations:**
- **Google Analytics:** For tracking and analyzing user interactions.
- **Google Tag Manager & AdSense:** For analytics and advertising.
- **Cookies & Web Beacons:** For user session management and analytics.

**Additional:**
- **Custom CSS Files:** (e.g., `styleIndex.css`, `styleRegister.css`, `styleLogin.css`) for custom styling.
- **Custom JS Files:** (e.g., `index.js`) for client-side logic.
